# Portfolio — YOUR NAME

Static portfolio site (HTML/CSS/JS, no build step).

## Customize
1. Replace `YOUR NAME` / `YN` in `index.html` and `script.js` (`NAME`, `ROLE`).
2. Add `assets/photo.jpg` (square, 720×720) and `cv.pdf` in the root.
3. Edit stats (`data-count`), skills, projects, and reviews in `script.js`; timeline in `index.html`.
4. Contact form: create a free form at formspree.io and replace `YOUR_FORM_ID` in `index.html`.
5. Replace `YOUR_USERNAME` and `you@example.com` social links.

## Run & deploy
Open `index.html` (or use VS Code Live Server). For GitHub Pages: push, then Settings → Pages → deploy from `main`.
